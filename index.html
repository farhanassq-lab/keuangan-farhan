DATA PORTABILITY

Backup & restore

Simpan salinan data ke file JSON pribadi. Restore akan menggabungkan data berdasarkan ID; data yang tidak ada di file tidak dihapus.

Backup data

Profil, akun, transaksi, kurs, target, budget, jadwal rutin, kategori kustom. File bukti tidak disalin ke JSON.

Pulihkan data

Hanya backup milik akun yang sama. Data dengan ID sama akan diperbarui.

File backup berisi data keuangan pribadi. Simpan di tempat aman dan jangan mengirimkannya ke orang lain. Pemulihan dilakukan bertahap; jika koneksi terputus, ulangi file yang sama untuk melanjutkan upsert tanpa menghapus data lain.

Akun & privasi

—

Data transaksi dibatasi menggunakan Supabase Row Level Security (RLS). Jangan pernah menaruh service_role key di frontend. Hanya URL project dan publishable/anon key yang boleh digunakan di sini.
